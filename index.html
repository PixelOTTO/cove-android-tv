Bring CoveTV to your TV.

  1. Get the APK

    Download it directly on your TV, or save it to a computer and move it over USB or your home network.

  2. Open and install

    Open the file with a file manager. If Android asks, allow that app to install unknown apps, then come back and continue.

  3. Make it Home

    Choose CoveTV when Android asks which Home app to use. You can change this later in CoveTV Settings.

Installing with ADB?

Use Android Platform Tools on a computer. The file name stays the same for every release, and -r updates an existing install and keeps its data.

adb devices adb install -r "CoveTV-Android-TV-launcher.apk"

For wireless ADB, put the TV and computer on the same Wi-Fi network. If your TV runs Android 13 or later with Wireless debugging, pair first, then connect with the address and port shown on the TV. Turn debugging off when you’re done. Need more help? Open the AI-assisted install guide.

Updates are optional. CoveTV can check its GitHub releases for a newer version and tell you when one is available. You can turn the checks off in Settings, and Android always asks before installing an update.
