A few simple steps

Bring CoveTV
to your TV.

Download the latest release, install it on your TV, then choose CoveTV as your Home app.

1
Get the APKDownload directly on your TV, or save it to a computer and transfer it over USB or your home network.
2
Open and installUse a file manager to open the APK. If prompted, allow that app to install unknown apps, then return and continue.
3
Make it HomeChoose CoveTV when Android asks which Home app to use. You can change the default later in CoveTV Settings.
Android TVGoogle TVAndroid 8.0+

Installing with ADB?

For a computer-to-TV install, download the APK and use Android Platform Tools. This filename stays the same for every release.

adb devices adb install -r "CoveTV-Android-TV-launcher.apk"

For wireless ADB, connect your TV and computer to the same Wi-Fi network. Pair first if your TV uses Android 13+ Wireless debugging, then connect with the address and port shown on the TV.

Need a hand? Open the AI-assisted install guide for a ready-to-use prompt and full instructions.

Community-made and transparent about its roots

Clear about its roots.

CoveTV is an unofficial community-maintained build based on CleanYourTV by Gathin and includes code from Free My TV by its contributors. This repository publishes APK releases, release notes, and notices; the CoveTV Android app source code is not currently published here. CoveTV is not affiliated with or endorsed by either project.
