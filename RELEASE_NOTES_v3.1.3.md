# CoveTV 3.1.3

- Fixes app tile sizing after the Android TV grid reports its final width, so the focus outline stays aligned at 5, 6, and 7 apps per row.
- Rebrands Cove as CoveTV with the supplied vibrant app icon and TV banner.
- Includes launcher settings backup and restore.
- Keeps the existing Android package identity and signing certificate so it updates an existing install.

Requires Android 8.0 or later. Install by sideloading the APK on an Android TV or Google TV device.
