# Cove 3.1.1

First Cove-branded release of the Android TV launcher.

- Replaces the CleanYourTV name with Cove.
- Uses the supplied 320×180 Cove Android TV banner.
- Includes the refreshed settings layout, focus color choices, and featured-app shelf control from 3.1.0.
- Keeps the existing Android package identity so it can update an existing installation.

Requires Android 8.0 or later. Install by sideloading the APK on an Android TV or Google TV device.
